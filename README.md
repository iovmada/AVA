# AVA Brebu

A static Romanian website for AVA Brebu. The site includes the homepage, pizzeria, restaurant and accommodation pages.

- [Figma homepage](https://www.figma.com/design/32nTqabvleQHyiAQThl7D4/Swissstaffing_local_DP?node-id=1597-2)
- [GitHub repository](https://github.com/iovmada/AVA)

## Local preview

Requires Node.js 18 or newer and no package installation.

```sh
npm run build
npm run dev
```

Open http://127.0.0.1:4173. Set `PORT` to use a different port.

The templates and menu data live in `site/`. Run `npm run build` after editing them to regenerate the HTML in `dist/`. CSS, browser JavaScript, fonts and images live directly in `dist/`.

## Hosting

Publish `dist/` as a static site. GitHub's `main` branch feeds the production DigitalOcean app at https://www.ava-brebu.ro. The full website is developed on `ava/full-website`; production currently serves the coming-soon page.

Before launch, confirm the proposed menu, room rates and hours, add the business's reservation and contact details, and complete the menu categories for which the design contains no listings.

## Menu approval

Open `/admin/` to edit the menu and preview Restaurant photos. The local preview saves drafts in the browser. The public pages are built from `site/menu.json` and the photos in `dist/assets/site/`.

Enable live submissions when the full site is ready for production.

1. In the AVA GitHub repository, activate a branch ruleset for `main`. Require pull requests, one approving review, review from code owners, and renewed approval after new commits. Prevent force pushes and branch deletion. Keep the menu app off the bypass list. The reviewer is `@iovmada` in `.github/CODEOWNERS`.
2. Install a dedicated GitHub App on `iovmada/AVA` with **Contents** and **Pull requests** read and write permissions. Use the app identity for the proposals so the reviewer can approve them from a separate GitHub account. Give the restaurant owner the submission code through a secure channel.
3. In DigitalOcean App Platform, deploy the Functions component from the `functions/` directory on `main` under route `/api`. Set the encrypted component variables `AVA_MENU_SUBMIT_CODE` (a randomly generated secret of at least 16 characters), `AVA_GITHUB_APP_ID`, `AVA_GITHUB_INSTALLATION_ID`, and `AVA_GITHUB_PRIVATE_KEY` (the PEM generated by GitHub, or its base64 encoding).
4. For the static site component, keep `main` as its source, enable automatic deploys, set the build command to `npm run build` and the output directory to `dist`. Set the build variable `AVA_MENU_PROPOSAL_URL=/api/menu/propose` once the Functions route is available.

The editor creates a proposal branch and opens a pull request. Review **Files changed**, then approve and merge on GitHub to deploy the new menu. Submitting a proposal does not modify the production branch. Restaurant photos are resized in the browser and committed alongside the proposed menu.
